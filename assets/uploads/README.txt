==================================================
FOLDER UPLOAD - LOST & FOUND CAMPUS
==================================================

Folder ini digunakan sebagai direktori penyimpanan 
file gambar (foto barang hilang/ditemukan) yang 
diunggah oleh pengguna melalui formulir pada file 
'lapor.html'.

Format file gambar yang didukung:
- .jpg / .jpeg
- .png
- .webp

Catatan: Karena proyek ini menggunakan HTML murni 
tanpa skrip backend (PHP/NodeJS), folder ini berfungsi 
sebagai simulasi direktori upload target.
