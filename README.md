# PNC Lost & Found Portal Campus

Sistem informasi dan formulir pelaporan barang hilang/ditemukan di area kampus berbasis **HTML5 Murni (Tanpa CSS & JavaScript)**.

Proyek ini dibuat untuk memenuhi tugas mata kuliah **Pemrograman Web**.

---

## 📁 Struktur Folder Proyek

```text
lost-and-found/
│
├── index.html            # Beranda Utama (Pencarian & daftar laporan terbaru)
├── lapor.html            # Formulir pelaporan barang hilang / ditemukan
├── dashboard.html        # Dashboard statistik & log rekapitulasi data
│
├── assets/
│   ├── images/           # Asset gambar & logo aplikasi
│   │   ├── logo.svg
│   │   └── default-item.svg
│   │
│   └── uploads/          # Direktori simulasi upload berkas foto
│       └── README.txt
│
└── README.md             # Dokumentasi proyek
🚀 Fitur Utama
Struktur Semantik HTML5:
Menggunakan elemen <header>, <nav>, <main>, <section>, <article>, <aside>, <figure>, dan <footer>.

Formulir Interaktif & Validasi HTML5:

Tipe input beragam: text, search, radio, checkbox, file, date, time, email, tel, hidden.

Validasi bawaan browser: required, pattern, maxlength, accept.

Pengelompokan elemen form menggunakan <fieldset> dan <legend>.

Rekapitulasi Data:

Tabel statistik laporan masuk dan status penyelesaian barang.

Log riwayat penanganan laporan.

💻 Cara Menjalankan Proyek
Clone atau unduh seluruh folder lost-and-found.

Buka file index.html langsung menggunakan browser favorit Anda (Chrome, Firefox, Edge, Safari).

Navigasi antar halaman dapat dilakukan melalui menu header di bagian atas.
